# Auth Flow Implementation Plan

> **For agentic workers:** Inline execution in this session (user requested immediate build).

**Goal:** Next.js app with two-step signup, login, dashboard, and env-password admin user list.

**Architecture:** Custom auth with Mongoose + bcryptjs + jose cookies; middleware for route protection.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind, Mongoose, bcryptjs, jose

## Global Constraints

- Passwords never stored plaintext; use bcryptjs (cost 10+)
- Secrets only via env; never commit `.env`
- Admin access only via `ADMIN_PASSWORD`, not DB roles

## File map

- `src/lib/db.ts` — mongoose connect
- `src/lib/user.ts` — User model
- `src/lib/session.ts` — cookie create/read/clear
- `src/lib/password.ts` — hash/verify
- `src/app/api/auth/signup-email/route.ts`
